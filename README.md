# Умный сев — лендинг с интерактивным демо

[Открыть сайт](https://SergeShchelokov.github.io/land/)

Лендинг повторяет фрейм [«Лендинг» в Figma](https://www.figma.com/design/xLqvlxrXj46Mys0FVp137S?node-id=22086-47206). В блок встроен работающий список полей и панель севооборота: выбор культур, календарь, чекбоксы, поиск, редактирование, валидация и сохранение демонстрационных данных в localStorage браузера.

Стек: Vue 3, TypeScript, Vite, Vuetify 0 и Reka UI. Проект самостоятельный, сервер и секреты не требуются.

## Локальный запуск

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

Лендинг: http://127.0.0.1:5188/land/. Отдельный экран сервиса: http://127.0.0.1:5188/land/demo.html.

```sh
npm test
npm run build
npm run preview
```

Готовая сборка находится в `dist`. Предпросмотр сборки: http://127.0.0.1:4173/land/.

## Публикация

GitHub Actions проверяет тесты, собирает проект и публикует `dist` в GitHub Pages при каждом push в `main`. Ручной запуск доступен в Actions → Deploy landing to GitHub Pages → Run workflow. В Settings → Pages выбран источник GitHub Actions. Для другого имени репозитория нужно изменить `base` в `vite.config.ts`.

Форма заявки демонстрационная: данные никуда не отправляются. Другие маркетинговые скриншоты сохранены как иллюстрации из исходного макета. Реальные интеграции и серверное хранение отсутствуют.
